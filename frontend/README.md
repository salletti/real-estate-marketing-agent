# Frontend

React frontend for the Real Estate Marketing Agent.

## Stack

- React
- TypeScript
- Vite
- TanStack Query
- Tailwind CSS

## Setup

```bash
npm install
npm run dev
```

The development server runs on http://localhost:5173 by default.

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Environment

Copy the example file if frontend-specific variables are needed:

```bash
cp .env.example .env
```

The backend API is expected to run on http://localhost:8000 in local development.
